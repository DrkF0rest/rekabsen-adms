User Guide

Quick steps to get REKABSEN up and running.

01

Connect a device

Start the REKABSEN server, then configure the server address and port 8080 on the fingerprint device. Make sure the device can reach the server computer over the network.

02

Monitor device connections

The Dashboard shows each device's serial number, IP address, and last connection time. Attendance records appear as they are received.

03

Search and export records

Use search, sorting, and page controls below the table to find records. Download XLSX exports all records matching the active filters.

04

Configure the database

Open Settings to choose SQLite or MySQL Server. Enter the MySQL connection details if needed, then choose whether to copy data to the destination.

05

Manage names and records

In Settings, change the display name for each device. Clear Data removes attendance records but keeps device and user data.
